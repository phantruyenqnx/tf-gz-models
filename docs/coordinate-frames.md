# Gazebo coordinate frames

Axis colour convention:

- 🔴 **X axis = RED**
- 🟢 **Y axis = GREEN**
- 🔵 **Z axis = BLUE**

Mnemonic: **RGB = XYZ**

Gazebo uses a right-handed coordinate system:

```
    Z (Blue)
    ↑
    |
    |
    +----→ X (Red)
   /
  /
 ↓
Y (Green)
```

- **X (Red):** typically points forward
- **Y (Green):** typically points left
- **Z (Blue):** typically points up
